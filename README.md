# UBND xã X – Trang trải nghiệm Mini App

Trang giới thiệu Zalo Mini App (bên trái) và bản chạy thử trong khung điện thoại (bên phải), host bằng GitHub Pages.

- `index.html`: trang giới thiệu.
- `app/`: bản build web của Mini App, sinh tự động từ repo mã nguồn.

## Cập nhật bản app

Trong thư mục mã nguồn `zalo-xa-demo`:

```bash
npm run build:showcase
```

Sau đó commit và push thư mục này.
